# Fitness & Workout Management System

A simple front-end mini project for recording and managing workout activities.

## Features
- Add exercise, workout type, duration and date
- View workout history
- Delete workout records
- Automatic workout count and total minutes
- Browser Local Storage

## Technologies
HTML, CSS, JavaScript

## Run
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
